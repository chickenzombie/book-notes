# Book Notes

Конспекты прочитанных книг в виде одностраничных визуальных выжимок. Начал с разработки и тестирования, дальше — всё, что цепляет. Не пересказ и не замена оригинала: только структура, ключевые идеи и то, что реально пригождается в работе и жизни.

## Как устроено

Статические страницы, ни сборки, ни зависимостей: открываются двойным щелчком по файлу.

```
index.html              полка
assets/                 общее: каркас, движок, шрифты
books/<slug>/           конспект: index.html + theme.css + icon.svg
books/_template/        заготовка для новой книги
tools/fonts.sh          обновить набор шрифтов
```

Общее у конспектов — механика: `assets/base.css` даёт каркас и служебные состояния, `assets/notes.js` — поиск, фильтр по разделам, полосу прочитанного и кнопку «наверх». Внешний вид общим не является: у каждой книги свой `theme.css`, и он волен переписать что угодно — палитру, шрифты, шапку, форму маркера. Как придумывать книге лицо, написано в самом [шаблоне темы](books/_template/theme.css).

Сами пункты лежат в HTML готовой разметкой, скрипт их не рисует. Поэтому конспект читается с выключенным JS, ищется поиском по странице, сохраняется целиком и печатается. Шрифты тоже лежат в репозитории — страница не ходит на сторонние домены.

Новая книга: скопировать `books/_template` в `books/<slug>`, пройти по меткам `[ЗАПОЛНИТЬ]`, придумать тему и дописать `<li>` на полку в корневом `index.html`.


## Права

Права на исходные книги принадлежат их авторам и издательствам. Конспекты некоммерческие и книги не заменяют. Формулировки, взятые из изданий, остаются собственностью правообладателей — по вопросам их использования обращайтесь к издательству, контакт указан на странице конкретной книги.
