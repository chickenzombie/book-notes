## Как читать

Конспект книги — одна страница: поиск по всем пунктам и фильтр по разделам. Пункты лежат в разметке готовыми, а не рисуются скриптом, поэтому страница читается с выключенным JS, ищется обычным поиском браузера, целиком сохраняется и нормально печатается. Шрифты лежат рядом со страницей — на сторонние домены она не ходит.

## Права

Права на исходные книги принадлежат их авторам и издательствам. Конспекты некоммерческие и книги не заменяют. Формулировки, взятые из изданий, приводятся как цитаты в информационных и учебных целях с указанием источника — по вопросам их использования обращайтесь к правообладателю, выходные данные указаны на странице каждой книги. **Если правообладатель возражает против публикации конспекта — напишите, страница будет снята.**
