# Book Notes

Конспекты прочитанных книг в виде одностраничных визуальных выжимок. Начал с разработки и тестирования, дальше — что попадётся. Не пересказ и не замена оригинала: только структура, ключевые идеи и то, что реально пригождается в работе.

**Открыть полку:** включите GitHub Pages в настройках репозитория (Settings → Pages → Deploy from a branch → `main` / root), после чего каталог будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Как это устроено

```
.
├── index.html                    ← каталог, витрина полки
├── books/
│   └── <slug>/
│       ├── index.html            ← сам конспект, один самодостаточный файл
│       └── README.md             ← выходные данные книги и права
├── _template/
│   └── index.html                ← заготовка для новой книги
├── .nojekyll                     ← отключает Jekyll: иначе Pages скроет _template/
└── LICENSE                       ← MIT, только на код
```

Каждый конспект — **один HTML-файл без сборки и зависимостей**. Скачал, открыл в браузере, работает. Единственный внешний ресурс — шрифты Google Fonts; без сети страница откатывается на системные и остаётся читаемой.

## Как добавить книгу

1. Скопируйте `_template/index.html` в `books/<slug>/index.html`, где `<slug>` — короткое имя латиницей (`clean-architecture`, `phoenix-project`).
2. Заполните шапку, разделы и карточки. В шаблоне отмечено комментариями, что куда.
3. Положите рядом `README.md` с выходными данными книги и ссылкой на издательство.
4. Допишите объект в массив `BOOKS` в корневом `index.html` — карточка появится на полке автоматически.

## Принципы

**Выжимка, а не пересказ.** Смысл в том, чтобы через год открыть страницу и за пять минут вспомнить книгу целиком. Если конспект начинает заменять чтение — он слишком подробный.

**Свои слова.** Формулировки автора цитируются минимально и всегда с указанием источника. Пояснения пишутся заново, а не переписываются из книги.

**Одна страница — одна книга.** Никакой навигации между главами, никаких вкладок с подгрузкой: всё на одном экране, ищется через `Ctrl+F` и встроенный поиск.

**Ссылка на оригинал обязательна.** На каждой странице — выходные данные, ISBN и ссылка, где книгу купить.

## Права

Права на исходные книги принадлежат их авторам и издательствам. Конспекты некоммерческие и книги не заменяют. Формулировки, взятые из изданий, остаются собственностью правообладателей — по вопросам их использования обращайтесь к издательству, контакт указан на странице конкретной книги.
